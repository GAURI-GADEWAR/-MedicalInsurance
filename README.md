# Medical Insurance Cost Prediction

## Project Overview

This project predicts medical insurance charges based on the age of an individual using a Simple Linear Regression model.

The project includes Exploratory Data Analysis, correlation analysis, model training, model evaluation, and a Streamlit web application.

## Dataset

The project uses the Medical Insurance Cost dataset.

The dataset contains information such as:

- Age
- Sex
- BMI
- Number of Children
- Smoking Status
- Region
- Medical Insurance Charges

For the Simple Linear Regression model, Age is used as the independent variable and Charges are used as the dependent variable.

## Machine Learning Model

Simple Linear Regression is used to predict medical insurance charges based on age.

### Input

Age

### Output

Predicted Medical Insurance Charges
